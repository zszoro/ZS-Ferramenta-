# Template - Padaria Completa

Usar `prompts/bakery-site.md` como prompt mestre.

Este template deve ser escolhido quando o nicho tiver:

- padaria
- paes
- confeitaria
- bolos
- doces
- salgados
- cafe da manha

O gerador atual ja cria preview completo para padarias com:

- menu fixo
- hero
- sobre/diferenciais
- produtos
- combo
- depoimentos
- contato/mapa
- rodape
