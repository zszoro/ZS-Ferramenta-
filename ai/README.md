# /ai

Camada de produto da IA desenvolvedora da ZS Ferramenta.

- `src/lib/ai-builder/context.ts`: prompt base, prompt de nicho e templates de componentes.
- `src/lib/ai-builder/rag.ts`: RAG local deterministico sem dependencia externa.
- `src/lib/ai-builder/agents.ts`: registro de agentes especializados.

Quando um provider real for conectado, esta pasta deve documentar orquestracao, limites de seguranca e ferramentas aprovadas.
