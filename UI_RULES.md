# UI_RULES.md - Regras de UI

- Todo botao visivel precisa executar uma acao real.
- Preview deve continuar visivel durante criacao e edicao.
- Evitar painels pesados que escondem o chat.
- Modal deve ter fechamento claro e foco visual.
- Navegacao dentro de preview deve usar anchors internas, nunca links que tirem o usuario do iframe sem intencao.
- Para sites de cliente, usar copy ficticia ate o cliente fornecer texto real.
- Para imagens, usar assets gratuitos coerentes e nunca copiar marca de referencia.
- Em edicoes, preservar o que ja existe e alterar apenas o alvo pedido quando possivel.
